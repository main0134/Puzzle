# 일러스트 직소 퍼즐 퀘스트 (Picture Puzzle Quest)

5단계 난이도와 10개의 고유한 캐릭터 일러스트 스테이지(총 50개 스테이지)로 구성된 인터랙티브 웹 직소 퍼즐 게임입니다.  
실제 직소 퍼즐처럼 튀어나온 곳(돌출부)과 들어간 곳(홈)이 맞물리는 인터로킹 구조를 수학적으로 구현하였으며, 하단 트레이에서 조각을 끌어와 판에 맞추는 직관적인 플레이 경험을 제공합니다.

---

## 🌟 주요 기능 및 특징

### 1. 5단계 난이도 체계
- **입문 (3×3 · 9조각)**: 퍼즐의 기본 규칙을 익히는 빠른 입문 단계 (3성 기준: 40초 이내)
- **쉬움 (4×4 · 16조각)**: 가볍게 즐길 수 있는 표준 퍼즐 (3성 기준: 90초 이내)
- **보통 (5×5 · 25조각)**: 배경과 캐릭터의 세밀한 묘사를 관찰하는 난이도 (3성 기준: 180초 이내)
- **어려움 (6×6 · 36조각)**: 테두리 조각 정리 및 높은 집중력이 요구되는 상급 퍼즐 (3성 기준: 300초 이내)
- **마스터 (7×7 · 49조각)**: 대형 격자의 마스터 챌린지 (3성 기준: 480초 이내)

### 2. 10개 스테이지 & 풍부한 배경의 캐릭터 일러스트
각 스테이지마다 독창적인 세계관과 캐릭터, 정교한 배경 일러스트가 제공됩니다:
1. **달빛 숲의 엘프 마법사 실피아** (신비로운 고대 세계수의 성소)
2. **네온 시티의 사이버 캣 해커 바이트** (비 내리는 네오 교토 루프탑)
3. **심해 산호초의 인어 수호자 코랄리아** (침몰한 아틀란티스 대리석 신전)
4. **벚꽃 신사의 여우 무사 렌** (황혼 노을빛 천년 신사 토리이)
5. **천공 비행선의 판다 탐험가 보보** (구름 위 떠다니는 부유섬 군락)
6. **은하계의 우주비행사 토끼 버니** (지구와 성운이 보이는 궤도 정거장)
7. **마법 도서관의 현자 부엉이 아르키메데스** (공중 부유 마법서와 고대 아카이브)
8. **크리스탈 계곡의 드래곤 라이더 아스타** (발광 수정 동굴 협곡)
9. **황혼 오아시스의 유목민 전사 타리크** (저녁별이 뜨는 사막 샘터)
10. **눈꽃 궁전의 얼음 정령 여왕 루미나** (오로라 눈꽃 빙하 궁전)

### 3. 정밀한 직소 퍼즐 알고리즘 (True Interlocking Jigsaw)
- 각 조각은 단순한 사각형 타일이 아닌, **둥근 머리와 잘록한 목 형태의 베지어 곡선**으로 제작된 돌출부(Tab, `+1`)와 홈(Blank, `-1`), 평평한 외곽선(`0`)을 갖습니다.
- 이웃한 조각끼리 수학적으로 완벽하게 맞물리는 토폴로지 맵(`generateJigsawEdges`)을 자동 생성합니다.
- SVG 클리핑 마스크(`clipPath`)를 통해 각 조각마다 원본 일러스트의 해당 영역이 고화질로 렌더링되며, 3D 베벨 음영 효과가 적용됩니다.

### 4. 하단 트레이 & 듀얼 컨트롤 (드래그 앤 드롭 & 클릭 결합)
- **판(Board)**: 상단에 위치하며, 슬롯마다 조각 모양의 점선 실루엣과 선택형 밑그림 가이드가 표시됩니다.
- **조각 보관함(Piece Tray)**: 아직 맞추지 않은 조각들이 판 아래 가로 일렬로 깔끔하게 나열되며, 좌우 스크롤 네비게이션을 지원합니다.
- **드래그 앤 드롭**: 트레이의 조각을 마우스/터치로 끌어다 판의 알맞은 슬롯에 드롭하면 찰칵(Snap) 소리와 함께 고정됩니다.
- **클릭 투 플레이**: 트레이의 조각을 클릭(선택 하이라이트)한 후 판의 빈 슬롯을 클릭하여 배치할 수도 있습니다.

### 5. 완성본 일러스트 확인 & 플레이 보조 기능
- **완성본 일러스트 버튼**: 클릭 시 원본 고화질 일러스트와 스토리, 캐릭터/배경 정보가 담긴 팝업 모달이 열립니다.
- **실시간 엿보기 (스페이스바 길게 누르기)**: 플레이 중 키보드 스페이스바를 누르고 있는 동안 판 위에 원본 이미지를 즉시 엿볼 수 있습니다.
- **투명 밑그림 가이드 토글**: 판 뒤에 반투명한 완성본 가이드를 투영합니다.
- **테두리 조각 필터**: 트레이에서 가장자리 조각만 남겨 먼저 외곽 틀을 맞출 수 있도록 돕습니다.
- **조각 번호 가이드**: 조각마다 고유 번호를 표시합니다.
- **자동 맞춤 힌트**: 잘못 놓여 있거나 트레이에 있는 조각 1개를 자동으로 올바른 슬롯에 맞춥니다.

### 6. 클리어 기록 & 영구 저장 (`localStorage`)
- 퍼즐 완성 시 폭죽 애니메이션(`canvas-confetti`)과 팡파르가 재생됩니다.
- **걸린 시간(⏱️ MM:SS)**, 이동 횟수, 별점(1~3성)이 산출되며 신기록 여부가 표시됩니다.
- 스테이지 선택 화면에 **`✓ 클리어` 완료 뱃지**, 별점, 최고 기록 시간이 실시간 갱신되어 영구 저장됩니다.
- 전체 50개 스테이지에 대한 통합 통계 및 진행률을 확인할 수 있습니다.

### 7. 내 사진 퍼즐 (Custom Puzzle)
- 사용자가 소장한 캐릭터 일러스트나 사진(PNG, JPG, WEBP)을 직접 업로드하여 5개 난이도 중 원하는 격자로 플레이할 수 있습니다.

### 8. Web Audio API 사운드 신디사이저
- 외부 음원 파일 다운로드 없이 브라우저 내장 오디오 오실레이터를 합성하여 선택음, 조각 교환음, 결합(Snap) 효과음, 힌트 차임, 클리어 팡파르를 지연 없이 재생합니다. (음소거 토글 지원)

## 🧩 직소 퍼즐 핵심 알고리즘 설명

### 1. 인터로킹 토폴로지 생성 (`src/utils/jigsaw.ts`)
$N \times N$ 격자에서 각 내부 경계면마다 돌출부(Tab)와 홈(Blank)을 상보적으로 할당합니다:
- 수평 경계면: $(r, c)$ 조각의 아래쪽이 `+1`(돌출부)이면, $(r+1, c)$ 조각의 위쪽은 반드시 `-1`(홈)이 됩니다.
- 수직 경계면: $(r, c)$ 조각의 오른쪽이 `+1`(돌출부)이면, $(r, c+1)$ 조각의 왼쪽은 반드시 `-1`(홈)이 됩니다.
- 최외곽 테두리: $0$(평평한 직선)으로 처리됩니다.

### 2. 베지어 곡선 조각 생성 (`createJigsawPath`)
각 모서리 사이를 선분으로 잇되, $sign \neq 0$인 경우 선분의 $35\% \sim 65\%$ 구간에 잘록한 목과 둥근 머리를 가진 3차 베지어 곡선(`C`)을 형성합니다. 이를 통해 실제 퍼즐과 동일한 결합 감각을 제공합니다.

### 3. SVG 클리핑 이미지 투영 (`JigsawPieceView.tsx`)
조각의 viewBox 내에서 전체 일러스트 이미지의 오프셋(`x = margin - col * cellW`, `y = margin - row * cellH`)을 정확히 계산하여, 각 조각이 캐릭터 일러스트의 본래 위치를 오차 없이 보여줍니다.

## 🚀 로컬 실행 방법

### 1. 패키지 설치
```bash
npm install
```

### 2. 개발 서버 시작 (포트 3000)
```bash
npm run dev
```
브라우저에서 `http://localhost:3000`으로 접속하여 플레이할 수 있습니다.

### 3. 프로덕션 빌드
```bash
npm run build
```

## 🎮 조작 팁
- **조각 이동**: 하단 보관함에서 원하는 조각을 드래그하여 상단 판의 알맞은 위치에 놓으세요.
- **클릭 조작**: 조각을 클릭한 뒤 판의 슬롯을 클릭해도 배치됩니다. 판에 놓인 조각을 클릭하면 보관함으로 되돌아옵니다.
- **완성본 보기**: 언제든 상단의 **완성본 일러스트** 버튼을 누르거나, **스페이스바를 꾹 누르고 있으면** 원본 그림을 즉시 확인할 수 있습니다.
- **보조 도구**: 조각 번호 표시(`Hash`), 테두리 조각 필터(`Layers`), 투명 밑그림 가이드, 자동 맞춤 힌트(`?`)를 적극 활용해 보세요.
